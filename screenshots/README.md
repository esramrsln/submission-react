# Screenshots untuk Submission

Simpan screenshot berikut di folder ini:

1. **1_ci_check_error.png** - CI check error karena pengujian gagal
2. **2_ci_check_pass.png** - CI check pass karena pengujian lolos
3. **3_branch_protection.png** - Branch protection pada halaman PR

## Cara Mengambil Screenshot

### 1. CI Check Error
- Buat perubahan yang menyebabkan test gagal
- Push ke branch baru dan buat Pull Request
- Screenshot halaman PR yang menunjukkan CI check error (tanda X merah)

### 2. CI Check Pass
- Perbaiki error dan push perubahan
- Screenshot halaman PR yang menunjukkan CI check pass (tanda centang hijau)

### 3. Branch Protection
- Buka Settings > Branches di GitHub repository
- Screenshot halaman branch protection rules untuk branch master/main
